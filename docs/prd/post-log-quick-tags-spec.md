## Problem Statement

해벽(haebyeok.app)의 인공외벽 이용자는 가기 전에 "지금 그 외벽이 붐비는지, 해가 드는지, 바람이 센지, 벽 상태는 어떤지"를 알고 싶어 한다. 지금은 혼잡도(여유/보통/혼잡)만 제보로 모이고, 그마저 기록 추가 시트 안의 선택 질문이라 참여가 적다. 날씨·그늘 체감과 벽 상태·주차·초보자 적합성 같은 현장 정보는 수집되지 않고, 그래서 "지금 가기 좋은 외벽"을 앱이 스스로 추천하지 못한다.

## Solution

등반 기록을 저장한 직후, 기록은 이미 안전하게 저장된 상태에서 "현장 분위기 3초만 알려주실래요?"라는 초대가 뜬다. 이용자는 키보드 없이 칩 몇 개(혼잡도 1개 + 태그 0~3개)만 탭해 보낸다. 제보는 즉시 해당 외벽 카드에 반영되고(수 분 내 모두에게), 쌓인 제보와 계산된 양달·응달, 날씨 예보, 운영 시간이 합쳐져 메인 화면에 "지금 사람 적고 운동하기 좋은 외벽 Top 3"가 자동으로 만들어진다. 로그인·프로필 없이, 공개되는 것은 외벽·시각·선택한 칩뿐이다.

## User Stories

1. As a 클라이머, I want 기록을 저장한 직후 현장 제보 초대를 보고 싶다, so that 성취감이 높을 때 부담 없이 참여할 수 있다.
2. As a 클라이머, I want 제보를 건너뛰어도 기록이 그대로 저장되길, so that 제보가 기록 작성을 방해하지 않는다.
3. As a 클라이머, I want "다음에 하기" 한 번으로 초대를 닫고 싶다, so that 귀찮지 않다.
4. As a 클라이머, I want 시트를 닫거나 뒤로 가기만 해도 건너뛴 것으로 처리되길, so that 별도 확인 없이 빠져나갈 수 있다.
5. As a 클라이머, I want 키보드 없이 칩 탭만으로 제보하고 싶다, so that 5초 안에 끝낼 수 있다.

## Implementation Decisions

- **범위**: 인공외벽 모드. 자연암벽/해안 암장은 제외한다.
- **전송 채널**: 새 서버를 만들지 않고, 기존 혼잡도 제보용 폼에 "태그" 단답형 항목 하나를 추가한다. 값은 고정 사전의 키를 쉼표로 이은 문자열이다.
- **읽기 채널**: 기존 게시된 CSV에 5번째 열(태그)을 추가한다. 기존 파서는 4번째 열까지만 읽으므로 하위 호환이다. 5번째 열이 없는 옛 행은 태그 없는 제보로 해석한다.
- **혼잡도는 필수 선택**: 태그만 보내는 제보는 허용하지 않는다. 기존 혼잡 집계(요일 종류·시간대 보정, 방금 제보 우선, 3건 미만이면 판단 보류)는 변경 없이 재사용한다. 라벨만 "한적해요"로 표시하고 저장값은 기존 `여유`를 유지한다.
- **혼잡도 질문 이동**: 기록 추가 시트 내부 질문을 저장 직후 시트로 옮긴다. 설정 플래그 하나로 이전 동작으로 되돌릴 수 있고, 플래그가 꺼져 있거나 엔드포인트가 비어 있으면 어떤 요청·DOM도 만들지 않는다.
- **노출 게이트**: 기능 켜짐, 방문 시각이 현재 이전이며 최근 7일 이내, 기존 남용 방지(방문당 1회·30분 쿨다운·외벽당 하루 2회·하루 5회)를 통과할 때만 초대한다. 통과하지 못하면 기존 저장 토스트만 보인다. 한 번의 제보(혼잡도+태그)는 기존 "보낸 제보" 장부에 한 건으로 기록한다.
- **태그 사전(고정, 화이트리스트)**: 일시적 — 양달 따뜻함, 응달 시원함, 바람 셈/추움. 지속적 — 벽 상태 좋음, 주차 편함, 초보자 붙기 좋음. 양달과 응달은 상호 배타.
- **유효시간**: 혼잡 제보 90분(기존 규칙), 날씨·바람 태그 3시간, 지속 태그 최근 30일. 최소 3건 미만이면 태그를 숨기고 "제보 모으는 중"을 표시한다.
- **방문이 3시간보다 오래되면 일시적 태그 행을 묻지 않는다**(혼잡도와 이용 편의 태그만).
- **어뷰징 방어**: 알 수 없는 키·중복·개수 초과는 무시. 같은 5분 구간의 동일 태그는 1건으로 센다. 계산된 양달/응달과 상반된 태그는 가중치 0.5.
- **추천 모듈(순수)**: 입력은 제보 목록, 외벽 목록, 현재 시각, 운영 여부, 날씨 예보(기온·돌풍), 계산된 양달/응달. 출력은 외벽별 태그 현황과 Top 3. 닫힌 외벽은 후보에서 제외, 혼잡 판단이 없는 외벽도 제외.
- **점수**: 최종 = 0.6×혼잡 + 0.25×쾌적 + 0.15×벽 품질. 혼잡은 여유 1/보통 0.5/혼잡 0. 쾌적은 0.7에서 시작해 돌풍·바람 제보 시 감점, 더운 날(26°C 이상) 응달 가점·양달 제보 감점, 추운 날(10°C 이하) 반대. 벽 품질은 "벽 상태 좋음" 비율을 스무딩. 제보 수가 적을수록 점수를 신뢰도로 할인한다. 가중치와 기온 기준은 초기값이며 출시 4주 후 재조정한다.
- **장애 대응**: 날씨 실패 시 쾌적 점수는 중립값, 제보 시트 실패 시 추천 블록만 숨기고 지도·기록은 정상 동작한다.
- **보상**: 로그인이 없으므로 새 배지는 만들지 않는다. 즉시 토스트, 카드 낙관적 반영, 이 기기에만 쌓이는 제보 횟수를 기록 탭에 표시한다. 횟수는 v1에서 백업 파일에 포함하지 않는다.
- **메인 화면**: 추천 블록 1개(Top 3), 갱신 시각과 산정 기준(ⓘ), 빈 상태에서 기록 추가로 가는 진입 버튼. 추천 블록 ②③(양달/응달, 초보자)은 이후 단계.
- **측정**: 기존 통계 도구로 시트 열림·전송·건너뜀, 추천 노출·탭 이벤트를 남긴다.
- **개인정보**: 공개 시트에는 외벽·시각·선택한 칩 키만 존재한다. 자유 텍스트 입력칸은 두지 않는다.

## Testing Decisions

- **좋은 테스트의 기준**: 내부 구현이 아니라 외부에서 관찰되는 동작만 검증한다. 입력(CSV 텍스트·시각·날씨·운영 여부·일조 계산)을 주고 결과(외벽별 칩, Top 3 순서, 제출 페이로드)를 확인한다.
- **seam은 하나**: 제보 CSV 텍스트와 주입된 환경 입력을 받아 "카드에 보일 태그 현황 + Top 3"를 돌려주는 순수 모듈의 공개 인터페이스. 제출 페이로드 생성(허용된 태그만, 혼잡도 필수, 방문시각 포함)은 같은 모듈 인터페이스의 일부로 다룬다. 화면 컴포넌트는 이 seam 위에서 얇게 유지해 별도 단위 테스트 대상으로 삼지 않는다.
- **검증할 동작**: 태그 셀 해석(알 수 없는 키·중복·과다·주입 문자열 무시), 5번째 열이 없는 옛 시트 호환, 유효시간 경계(90분/3시간/30일 직전·직후), 3건 미만 숨김, 양달·응달 상충 처리, 5분 구간 중복 계산, 닫힌 외벽 제외, 제보 부족 외벽 제외, 더운 날/추운 날/돌풍 시 순위 변화, 신뢰도 할인, 날씨 실패 시 중립 처리, 자정·시간대 경계, 동점 처리.
- **선례**: 작업 저장소의 기존 혼잡도 제보 모듈 테스트(CSV 파싱·집계·전송 제한)가 같은 방식(순수 입력→출력)이므로 그 형식을 따른다. 이 미러 저장소에는 테스트가 없어 확인하지 못했다.

## Out of Scope

- 로그인, 프로필, 배지·랭킹 경쟁
- 한 줄 메모 공개 (v1.5에서 운영자 승인제로 별도 진행)
- 사진 제보, 푸시 알림
- 실시간 소켓·서버 이전 (제보량이 늘면 기존 Worker 확장을 별도 검토)
- 추천 블록 ② 양달/응달, ③ 초보자 외벽
- 자연암벽·해안 암장 기능
- 제보 횟수의 백업 파일 포함
