# CLAUDE.md (작업 저장소 루트용 초안)

해벽(haebyeok.app): 지금 열려 있는 실외 인공암벽장과 양달·응달을 보여주는 지도 앱.
서버·빌드 없는 바닐라 JS(ES 모듈) 정적 웹앱이며, 한 줄 타임라인용 Cloudflare Worker가 하나 있다.
(실제 명령과 폴더 구조는 이 저장소의 README·`package.json`을 기준으로 한다. 아래는 확인된 범위만 적었다.)

- 개발 서버: `npm run serve`, 테스트: `npm test`
- 배포 절차: `docs/system/deploy.md`
- 배포용 미러 저장소(`open-wall`)가 따로 있다. 거기서 `src/`나 `data/`를 고치지 않는다.

## 지켜야 할 원칙
1. **개인정보를 수집하지 않는다.** 기록은 이 브라우저(localStorage)에만 저장하고 전송하지 않는다. 서버 저장이 필요한 기능(현장 제보, 링크 제보)은 외벽·시각·선택한 칩·링크처럼 개인을 식별하지 않는 값만 받는다. 이 약속을 바꾸는 변경은 먼저 사용자에게 확인한다.
2. **안전·운영 정보는 사람이 승인한 뒤에만 게시한다.** 휴관, 운영시간, 요금, `suspended` 같은 값은 자동 수집·LLM 추출 결과를 그대로 `data/`에 쓰지 않는다. 자동으로 보여줄 수 있는 것은 "공지가 있어요 + 원문 링크 + 확인 시각"까지다. `checked_at`은 사람이 확인했을 때만 갱신한다.
3. **자동 수집은 예의 있게.** 식별 가능한 User-Agent, 느린 주기(시간 단위 이상), robots.txt 존중, 403/429에서 중단, 차단 우회 금지, 사실과 변경분만 저장하고 원문 링크를 노출한다. 네이버·인스타그램은 공식 API, 이용자 제보, 링크 연결만 쓴다.
4. **기능은 설정으로 끌 수 있게.** 외부 요청이 따르는 기능은 설정 값이 비면 요청과 DOM을 만들지 않는다(기존 `config.boardUrl` 방식).
5. **순수 모듈 + 테스트.** 계산·파싱·랭킹 로직은 화면과 네트워크에서 분리한 순수 함수로 만들고, 입력→출력 테스트로 검증한다. 기존 `crowd.js` 테스트 형식을 따른다.
6. **모르는 값은 비워 둔다.** 요금, 위치, 확인일을 추정해 채우지 않는다.
7. **접근성.** 색만으로 상태를 구분하지 않고, 터치 영역 44px 이상, 모션 줄이기 설정을 존중한다.

## 작업 방식
- 큰 작업은 먼저 계획을 말하고 확인을 받는다.
- 한 번에 한 작업, 한 브랜치. 데이터(`data/`) 변경과 화면 변경은 가능하면 다른 커밋으로 나눈다.
- 데이터를 바꿀 때는 원문과 계산 결과를 같이 보여 사람이 대조할 수 있게 한다.
